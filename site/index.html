The HUD that follows the app you're using.

Pick any window and Syspeek shows that app's CPU, memory, threads and file descriptors live, in a small panel that floats over your desktop. Docker and Kubernetes health come along when you want them.

install
$ curl -fsSL https://raw.githubusercontent.com/codeafridi/Syspeek/main/install.sh | sh

The same one line works on every OS because Qt ships inside the app. See Install for what each command does.

syspeek

What it shows

One panel. The numbers that matter.

Focused application

PID, CPU percent and resident memory of the window you are using, plus threads, open files and context switches. Refreshed every second.

Docker

Container count at a glance, with unhealthy, restarting and recently exited containers flagged.

Kubernetes

Problem pods (CrashLoopBackOff, OOMKilled, image pull failures) and deployments short on ready replicas, from your current kubectl context.

Runs where you work

Real focus tracking on GNOME, KDE, Hyprland, Sway, niri and plain X11. Native collectors on macOS and Windows. Anything an OS cannot provide is labelled not supported on this OS, never silently blank.

Get started

Pick your OS. One line each.

Linux recommended

Installs to your home directory, adds a syspeek command and starts at login. Works on Ubuntu, Debian, Fedora, Arch, openSUSE, Alpine and friends (64 bit, glibc 2.34 or newer).

bash
$ curl -fsSL https://raw.githubusercontent.com/codeafridi/Syspeek/main/install.sh | sh

No curl on the box? wget variant and details. Alternatives: .deb, AppImage, SHA256SUMS.

macOS

The same line fetches the latest DMG, copies Syspeek.app to /Applications and registers login autostart. Needs macOS 12 Monterey or newer. No permissions required, and the installer clears the quarantine flag so Gatekeeper stays quiet.

terminal
$ curl -fsSL https://raw.githubusercontent.com/codeafridi/Syspeek/main/install.sh | sh

Prefer the manual path? Download the DMG, or follow docs/macos.md.

Windows

Installs into your user directory with syspeek on PATH and login autostart. Needs Windows 10 or newer. Just PowerShell, no Git Bash.

powershell
PS> irm https://raw.githubusercontent.com/codeafridi/Syspeek/main/cpp/packaging/windows/install.ps1 | iex

Fan of setup wizards? Download the MSI or portable zip. SmartScreen may ask once: choose Run anyway. Details: docs/windows.md.

After install: syspeek to run it, syspeek status to check it, syspeek stop to quit it, syspeek update to upgrade. Docs and the full source live in the repository.
