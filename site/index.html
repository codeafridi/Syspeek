A tiny, always on top HUD for the app you're focused on.

No more hunting through top. Syspeek follows the window you're using and shows that application's CPU and memory plus optional Docker and Kubernetes health in a compact panel that stays out of your way — on Linux, macOS, and Windows, with native collectors on each.

install
$ curl -fsSL https://raw.githubusercontent.com/codeafridi/Syspeek/main/install.sh | sh

The same one line installs on all three platforms. Self-contained build — Qt is bundled, so there's no compiler or Qt runtime to install. Starts at login. On Windows: irm raw.githubusercontent.com/codeafridi/Syspeek/main/cpp/packaging/windows/install.ps1 | iex (PowerShell). Also available: the AppImage, .deb, DMG, and MSI.

syspeek

What it shows

One panel, the numbers that matter.

Focused application

The processes behind the window you're using right now — PID, CPU percentage, resident memory, plus threads, file descriptors, and context switches — updated live.

Docker

Running container count, plus flags for unhealthy, restarting, and recently exited containers.

Kubernetes

Problem pods (CrashLoopBackOff, image-pull failures, OOMKilled) and deployments with too few ready replicas, from your current kubectl context.

Runs where you work

GNOME, KDE, Sway, niri, and X11 on Linux; native focus and collectors on macOS and Windows. Features an OS cannot provide are shown as not supported on this OS — never silently blank.

Optional integrations run off the UI thread, so a missing tool never blocks the overlay.

Compatibility

Runs on your desktop.

On Linux, built and tested on Ubuntu, Debian, Fedora, RHEL 9 clones, openSUSE, Arch, and Alpine. The installer ships Qt 6 with the app, so it also runs on distros that don't package Qt 6 like openSUSE Leap, Amazon Linux 2023, and similar.

  • Linux — portable install (x86-64, glibc ≥ 2.34) or from source with your distro's Qt 6 (RHEL family via EPEL; Alpine uses musl).
  • macOS (beta, 0.7+) — DMG with Qt bundled, minimum macOS 12 (Monterey); no permissions required. Unsigned build: right-click → Open on first launch.
  • Windows (beta, 0.8+) — MSI or portable zip, Windows 10 or newer; native collectors (SCM, EventLog, PDH, TCP stats). Unsigned build: More info → Run anyway on first launch.
  • Controls — syspeek stop, syspeek disable, syspeek update, syspeek uninstall (per-OS verb sets: run the installer with -h; Windows autostart is syspeek --autostart=on|off|status).

Get started

Pick your platform.

One line recommended

Linux, macOS, or Windows (Git Bash). Adds a syspeek command, starts at login, and sets up the Linux focus bridge when needed.

any OS
$ curl -fsSL https://raw.githubusercontent.com/codeafridi/Syspeek/main/install.sh | sh

.deb Debian / Ubuntu

Native package. Installs /usr/bin/syspeek, a user unit, and a launcher.

deb
$ sudo apt install ./syspeek_0.8.1_amd64.deb

Grab the .deb + SHA256SUMS from the latest release, verify with sha256sum -c SHA256SUMS --ignore-missing.

AppImage Linux

One file, no install step. Download it, make it executable, run it. Self-updates via delta (.zsync on the release page, use AppImageUpdate).

appimage
$ curl -fLO https://github.com/codeafridi/Syspeek/releases/latest/download/Syspeek-0.8.1-x86_64.AppImage && chmod +x Syspeek-0.8.1-x86_64.AppImage && ./Syspeek-0.8.1-x86_64.AppImage

DMG macOS

App bundle with Qt included. Copy to /Applications (or ~/Applications without admin), then first-run it once so Gatekeeper allows the unsigned build.

dmg
$ curl -fLO https://github.com/codeafridi/Syspeek/releases/latest/download/Syspeek-0.8.1-macos.dmg

Or use the one-liner above — it fetches the DMG and installs the bundle + LaunchAgent + syspeek command for you. Steps for the manual path: docs/macos.md.

PowerShell / MSI Windows

Portable install into %LOCALAPPDATA%\Syspeek with syspeek shims on PATH and HKCU Run autostart. From PowerShell, no Git Bash needed.

powershell
PS> irm https://raw.githubusercontent.com/codeafridi/Syspeek/main/cpp/packaging/windows/install.ps1 | iex

Prefer a native installer? Grab the .msi (or portable zip + SHA256) from the latest release. Details: docs/windows.md.
