The HUD that follows the app you are using.

Pick any window and Syspeek puts that app's CPU, memory, threads, file descriptors, disk and network throughput in a small panel that floats over your desktop. Click once and the same binary opens a full console for the whole machine: host, disks, GPU, sensors, containers, Kubernetes, databases, traces and what the cloud is billing you.

What it shows

One panel over your app. Thirty-two views behind it.

The app you are using

PID, CPU, RSS, threads, open files and context switches, added up over the app's whole process tree, not one PID. Disk read and write rates, TCP throughput and listening ports per process, sampled from the kernel once a second.

The machine under it

Host CPU and steal, memory, load, per-device disk throughput and utilisation, network interfaces, hwmon temperatures, fans and power, battery health, and GPU utilisation with the process holding it. Anything an OS cannot report is labelled as such, never left blank.

The services you run

Docker containers with live CPU, memory, network and PIDs through the Engine API. Kubernetes pods, deployments, nodes and metrics-server usage. systemd units, launchd jobs and Windows services. A local PostgreSQL client for cache hit rate, commits, deadlocks and the slowest statements.

The bills and the pager

OTLP traces, DogStatsD metrics, synthetic HTTP checks and a Prometheus endpoint on the receiving end. Cloud instance identity, accrued cost and the provider's own billed spend. Alerts, incidents, SLO burn and webhooks to the receiver you already own.

  • Local only. No account, no telemetry, no phone home. The only outbound calls are ones you switch on: cloud metadata, your own webhook, your own Prometheus scraper.
  • Honest about the gaps. A surface the OS will not give up says so on the panel. macOS TCP counters need root, Windows has no load average, and the console prints those sentences instead of a zero.
  • One static binary. C++20 and Qt 6. Started from a .deb, a DMG, an MSI, an AppImage, Homebrew, Scoop or a single shell line.

Get started

Click your OS. Copy one line.

bash
$ curl -fsSL https://raw.githubusercontent.com/codeafridi/Syspeek/main/install.sh | sh

Installs for your user only, puts syspeek on PATH and starts it at login. Runs on Ubuntu, Debian, Fedora, Arch, openSUSE, Alpine and other 64 bit distros with glibc 2.34 or newer. No curl? The installer falls back to wget, busybox, or your package manager.

Prefer a package file? Download the .deb or the AppImage from Releases. The AppImage updates itself over zsync.

terminal
$ curl -fsSL https://raw.githubusercontent.com/codeafridi/Syspeek/main/install.sh | sh

Downloads the latest DMG, copies the app into Applications and turns on login autostart. Needs macOS 12 Monterey or newer. No permissions asked, and the installer clears Gatekeeper for you.

Prefer a package file? Download the DMG from Releases. TCP health is gated on macOS: the kernel will not hand those counters to an unprivileged reader, and the panel says so.

powershell
PS> irm https://raw.githubusercontent.com/codeafridi/Syspeek/main/cpp/packaging/windows/install.ps1 | iex

Open PowerShell, paste the line, done. Installs into your user folder, puts syspeek on PATH and starts it at login. Needs Windows 10 or newer. No Git Bash required.

Prefer a setup wizard? Download the MSI from Releases. SmartScreen may ask once, choose Run anyway.

After install: syspeek to run it, syspeek status to check it, syspeek stop to quit it, syspeek update to upgrade.
